The signature never leaves this machine: the page posts it to the dashboard on 127.0.0.1, which turns it into the key that decrypts the saved passphrase, checks the passphrase still opens the operator keystore, and caches it in RAM for the chosen time, exactly like ./unlock.sh. Only the owner wallet's signature works.

One-time setup

Save the operator passphrase once, sealed with your wallet's signature. After this you only sign.

Back to the dashboard. The old passphrase form (Arm collector… on the dashboard) still works if you prefer typing it.
